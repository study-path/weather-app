# 🌤️ Weather App

🔗 **Live Demo:** [weather-app-portfolioproject.vercel.app](https://weather-app-portfolioproject.vercel.app/)

A modern, responsive, and lightweight Weather Application built with React, Vite, and Tailwind CSS. The app allows users to search for real-time weather conditions globally, delivering key metrics in a clean, user-friendly interface.

## 🛠️ Tech Stack & Architecture

- Frontend Library:React 19 (Hooks, Functional Components)
- Build Tool: Vite
- Styling: Tailwind CSS (via `index.css`)
- Deployment: Vercel
